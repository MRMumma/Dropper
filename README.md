# Dropper

A 2D obstacle-avoidance game developed using Unity and C#.

## About the Game

Dropper is an interactive game in which players control a character to avoid falling obstacles. The game challenges players to react to incoming obstacles and survive as long as possible.

This project was developed to apply object-oriented programming concepts, game development techniques, and problem-solving skills using C# and the Unity game engine.

## Technologies Used

- **Programming Language:** C#
- **Game Engine:** Unity
- **Version Control:** Git and GitHub
- **Development Platform:** Windows

## Features

- **Player Movement:** Interactive left and right movement controls.
- **Obstacle Spawning:** Falling obstacles that players must avoid.
- **Collision Detection:** Detects interactions between the player and obstacles.
- **Scoring System:** Tracks player performance during gameplay.
- **Pause Functionality:** Allows players to pause gameplay.
- **Responsive Layout:** Scripts to manage screen sizing and object positioning.

## Technical Implementation

The game uses C# scripts to manage different aspects of gameplay.

Some of the primary scripts include:

- `PlayerMovement.cs` — Controls player movement and user input.
- `SpawnBall.cs` — Handles obstacle spawning.
- `Scoring.cs` — Manages the scoring system.
- `Pause.cs` — Handles pause functionality.
- `SceneChanger.cs` — Manages scene transitions.
- `KeepScreenSize.cs` — Supports screen sizing behavior.

The project demonstrates programming concepts such as conditional logic, methods, event handling, and organizing functionality into separate components.

## How to Run

1. Clone or download this repository.
2. Open the project using Unity Hub.
3. Install the Unity Editor version specified in `ProjectSettings/ProjectVersion.txt`, if necessary.
4. Open the game's main scene.
5. Press Play to start the game.
